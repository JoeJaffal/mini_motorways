# Protect road features from critic-loss updates

Engineering decision,25November2026. The restored policy's frozen native300-second lesson probe finds poor finite-return calibration. In five of seven nondegenerate sampled shared-encoder batches, value-loss gradients oppose actor gradients. In two pair batches their projection cancels about94percent of the actor component before optimizer processing. One nearzero actor-gradient batch is excluded from directional interpretation. These are sampled MonteCarlo gradients, not actual PPO epoch/Adam updates, so this motivates a bounded intervention without proving causation.

Prepare a separate `CityRoadChoiceDetachedCriticPolicy`: retain every weight, action/value prediction, and named Adam state of the Wait-restored candidate; detach the features supplied to the critic's value head. The value head still learns native return predictions. Road features learn from policy/entropy losses. Both Wait correction modules remain frozen at their verified zero outputs. No planner, imitation labels, reward change or simulator change. Original candidates and both active comparisons remain intact.

This is a smaller engineering intervention than an independent critic encoder. [Andrychowicz et al., What Matters In On-Policy Reinforcement Learning?](https://arxiv.org/html/2006.05990v1) found separate policy/value networks useful on four of five continuous-control environments. That motivates testing gradient interference; it does not validate this stop-gradient architecture or guarantee gains in this game. Features will still change as the actor learns, and a poorly fitted value baseline can still add variance. Global gradient clipping and the existing critic rate remain unchanged.

Checks required: identical outputs/weights/Adam on migration and reload; value-only backpropagation reaches only the value head; actor gradients still reach roads/encoder; a disposable PPO resume retains frozen Wait/prior and native reward/terminal contracts. No production launch until these pass and capacity is available. Prepared single-arm continuation would use262144added decisions, fixed65k/131k/final reviews,300-second lessons,8city+4pair+4single reset mix, retained optimizer and validated acceleration. Compare against its exact starting policy and retained original. This is an engineering recipe test; it cannot attribute a gain solely to detachment without a matched control.

Readiness gates are unchanged. No automatic overnight launch or promise of score improvement.


Scope clarification: this gradient probe evaluates the Wait-restored candidate on300-second lessons, whereas its critic was last trained jointly with different Wait behavior and60-second lessons. Changed policy/state distribution and return objective can themselves explain stale value estimates. Opposing sampled gradients are not inherently an implementation bug, and the probe does not establish that critic interference caused the original reset-arm regression. Detachment is a bounded protection hypothesis while adapting road/value learning, with fresh performance checks still required.
